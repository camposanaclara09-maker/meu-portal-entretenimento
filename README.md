
# Meu Portal de Entretenimento Digital

## Sobre o projeto

Este projeto foi desenvolvido para a Agenda 13 da disciplina de Desenvolvimento de Sistemas I.

O site apresenta três seções principais:

- Filmes e Séries
- Música e Podcasts
- Games e Tecnologia

## Tecnologias utilizadas

- HTML5
- CSS3
- CSS Reset
- Flexbox

## Recursos utilizados

- CSS Inline, Interno e Externo.
- Classes e IDs.
- Organização em três colunas.
- Imagens ilustrativas.
- Layout adaptável para diferentes telas.

## Arquivos do projeto

- portal.html
- index.html
- estilo.css
- reset.css
